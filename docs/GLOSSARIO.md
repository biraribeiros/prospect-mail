# Glossário

| Termo | Significa |
|---|---|
| ICP | Perfil de cliente ideal (setor, cidade, porte) |
| Sprint / Etapa | Um bloco de trabalho entregue e conferido |
| Hunter | Módulo que encontra empresas, contatos e sinais |
| Sinal comercial | Fato que indica momento de compra (vaga aberta, expansão, evento) |
| Hipótese | Explicação de por que abordar uma empresa agora, com provas |
| Evidência | Registro de onde um dado veio (fonte, link, data, confiança) |
| Catch-all | Domínio que aceita qualquer email; não dá para saber se a caixa existe |
| Bounce | Email devolvido (caixa inexistente ou cheia) |
| SPF / DKIM / DMARC | Três "carimbos" de DNS que provam que o email é legítimo |
| Domínio secundário | Domínio extra só para prospecção, protegendo o domínio principal |
| Aquecimento | Aumentar envios aos poucos para ganhar reputação |
| Disjuntor | Trava que pausa os envios se muitos emails voltarem |
| Dry run | Simulação: nada é enviado de verdade |
| Mailpit | Caixa de email falsa para testes |
| Rspamd | Medidor de "risco de spam" de uma mensagem |
| LGPD | Lei brasileira de proteção de dados |
| CRM | Sistema onde o time comercial acompanha negociações |
